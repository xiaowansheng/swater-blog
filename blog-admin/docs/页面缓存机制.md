# 页面缓存机制

## 1. 目标

页面缓存用于避免后台标签页切换时重复挂载组件，保留：

- 表单输入
- 滚动位置
- 页面筛选条件
- 已加载的数据和局部状态

## 2. 核心实现

基于 [react-activation](https://github.com/CJY0208/react-activation) 的 `KeepAlive` 实现，配合多标签页（Tabs）体系工作。历史上的手写 `RouteCache`/`ComponentCache` 方案已删除，当前只有这一套。

关键文件：

- [main.tsx](../src/main.tsx)：最外层包裹 `<AliveScope>`
- [BasicLayout.tsx](../src/layout/BasicLayout.tsx)：用 `<KeepAlive name={pathname}>` 包裹 `<Outlet>` 渲染结果
- [routes.ts](../src/config/routes.ts)：`keepAlive` 配置项
- [tabs.ts](../src/store/tabs.ts)：标签页与缓存的联动（移除/刷新标签时同步清理缓存）

缓存键为 `pathname + 刷新种子`，刷新标签页时 BasicLayout 会更换种子强制重新挂载。

## 3. 如何配置

在 `routeConfig` 中配置 `keepAlive`：

```tsx
const routeConfig = [
  { path: '/dashboard', component: Dashboard, title: '仪表盘', keepAlive: true },
  { path: '/article/edit/:id', component: ArticleEdit, title: '编辑文章', keepAlive: true },
  { path: '/simple-page', component: SimplePage, title: '简单页面', keepAlive: false },
];
```

## 4. 适用场景

### 建议开启缓存

- 编辑页
- 列表页
- 配置页

### 建议关闭缓存

- 实时数据页
- 一次性操作页
- 简单静态页

## 5. 常用操作

标签页 store（`useTabsStore`）已封装好缓存联动，业务代码应调用 store 方法而不是直接派发事件：

```ts
const { removeTab, refreshTab } = useTabsStore()

removeTab('/article/edit/123')   // 关闭标签并清理 KeepAlive 缓存
refreshTab('/article/edit/123')  // 刷新指定页面缓存
```

底层通过 `tab-remove` / `tab-refresh` 自定义事件通知 `BasicLayout` 调用 `useAliveController` 的 `drop` / `refresh`。

## 6. 调试建议

- 缓存页数量可在 `useAliveController().getCachingNodes()` 中查看
- 关注事件监听器和副作用是否在页面失活时正确处理（`useActivationEffect` 或对照 `when` 参数）
- 缓存丢失常见原因：`KeepAlive` 的 `name`/`key` 变化、标签被关闭触发了 `drop`

## 7. 维护规则

- 页面缓存只保留一份主文档，即本文档
- 代码实现变化时，优先更新本文档和相关源码注释
